# CI-01: isolate concurrent printenv test captures

Woodpecker #104 and #105 ran Linux workflows concurrently on the local
backend. #105 passed core/source tests then failed with the printenv equals
diagnostic captured as empty. The script used fixed host /tmp filenames for
stderr, allowing concurrent invocations to truncate or remove each other's
capture. These host files are separate from the redirection test inside the
cannedBSD private filesystem.

Each invocation now creates a unique mktemp directory and cleans it on exit
or handled termination. Both stderr captures use that directory. Runtime and
expected command behavior are unchanged. Shell syntax and diff checks pass;
concurrent Linux validation and exact CI are pending. Guest acceptance is not
required for this host-test-only isolation change.
