## 3. File-Scope Statics Audit & Multi-Invocation Reset Mechanism

Analysis of `upstream/netbsd/usr.bin/wc/wc.c` confirms:
- **Statics present:** `tlinect`, `twordct`, `tcharct`, `tlongest` (`wc_count_t`), `doline`, `doword`, `dobyte`, `dochar`, `dolongest` (`bool`), and `rval` (`int`) — 10 scalar static variables in total.
- **Zero pointer statics exist** across the translation unit; no heap allocations or pointer caches persist across calls (zero heap-use-after-free risk, unlike `ls.c`).
- **Isolation Mechanism:**
  - In upstream NetBSD, `wc.c` relies on ELF process start BSS zeroing; `main()` does *not* internally zero `doline`, `doword`, `dobyte`, `tlinect`, or `rval`. In a single-process guest runtime sharing a data segment across command executions, stale flags (e.g. `dobyte = true` from `wc -c`) would leak into subsequent `wc` invocations.
  - To maintain byte-for-byte unmodified upstream source while guaranteeing strict isolation, `compat/netbsd/include/cannedbsd_wc_state.h` defines:
    ```c
    #define setlocale(cat, loc) \
        ((void)(tlinect = twordct = tcharct = tlongest = 0, \
                doline = doword = dobyte = dochar = dolongest = false, \
                rval = 0), \
         cb_libc_setlocale(cat, loc))
    ```
  - This header is applied **exclusively to `wc.c`'s translation unit via `-include`** in both `Makefile` and `platform/mac68k/CMakeLists.txt`. Standard shared compat headers like `compat/netbsd/include/sys/file.h` remain faithful and contain zero command-private state.
  - Because `main()` in `wc.c` unconditionally executes `(void)setlocale(LC_ALL, "");` as its very first statement (line 91) prior to `getopt()`, all 10 scalar variables are deterministically reset to 0 / false on every entry.
  - In addition, `cb_libc_start()` resets standard `getopt` state (`cb_libc_optind = 1`, `cb_libc_opterr = 1`, `cb_libc_optopt = '?'`, `cb_libc_optreset = 0`) before dispatching to `main()`.
  - **Interim Scoping:** This correctness depends on a specific property of pinned `wc.c` (unconditional `setlocale` on entry) rather than general runtime safety. It is explicitly scoped as an interim per-command mechanism that will be subsumed when the generalized statics reset mechanism (`STATICS-RESET-01`) lands.
