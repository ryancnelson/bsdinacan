## 2. Green (Implementation & Verification)

- **Libc & Compat Veneer (`libc/include/wchar.h`, `libc/include/wctype.h`, `compat/netbsd/include/sys/file.h`, `compat/netbsd/include/sys/types.h`, `libc/cb_libc.c`, `include/cannedbsd/libc.h`):**
  - Added `libc/include/wchar.h` defining `mbstate_t`, `wint_t`, `wchar_t`, and prototype `cb_libc_mbrtowc`.
  - Added `libc/include/wctype.h` defining `wint_t` and mapping `iswspace` to `cb_libc_iswspace`.
  - Added `compat/netbsd/include/sys/file.h` including `<fcntl.h>`.
  - Added `typedef uint64_t u_quad_t;` and `typedef int64_t quad_t;` in `compat/netbsd/include/sys/types.h`.
  - Implemented `cb_libc_mbrtowc` and `cb_libc_iswspace` in `libc/cb_libc.c` for ASCII/C-locale single-byte character conversion.
  - Extended `format_output` in `libc/cb_libc.c` to support unsigned decimal formats (`%u`, `%lu`, `%llu`) with bounded 1-32 field width, satisfying NetBSD `wc`'s `WCFMT` (`" %7llu"`).
- **Stack Budget & Module Registration (`commands/wc_module.c`):**
  - `wc.c`'s `cnt()` function allocates two `MAXBSIZE` (65536-byte) automatic buffers (`u_char buf[MAXBSIZE]` and `wchar_t wbuf[MAXBSIZE]`), requiring ~320KiB of stack. `commands/wc_module.c` defines `cb_wc_program` with a 512KiB per-command stack budget.
- **Upstream Import & Bootstrap Retirement:**
  - Pinned `upstream/netbsd/usr.bin/wc/wc.c` byte-for-byte unmodified.
  - Removed `commands/wc.c` in the same commit.
- **Target Parity (`Makefile`, `platform/mac68k/CMakeLists.txt`):**
  - Updated `Makefile` to compile `netbsd_wc.o` from `upstream/netbsd/usr.bin/wc/wc.c`.
  - Updated `platform/mac68k/CMakeLists.txt` to build `cb_wc` from `upstream/netbsd/usr.bin/wc/wc.c` with `${ROOT}/compat/netbsd/include` and `${ROOT}/libc/include`.
  - Passes `tests/test_build_parity.py` (`BUILD-SYNC-01`).

## 3. File-Scope Statics Audit

Analysis of `upstream/netbsd/usr.bin/wc/wc.c` confirms:
- Statics present: `tlinect`, `twordct`, `tcharct`, `tlongest` (`wc_count_t`), `doline`, `doword`, `dobyte`, `dochar`, `dolongest` (`bool`), `rval` (`int`).
- **Zero pointer statics exist** across the translation unit; no heap allocations or pointer caches persist across calls (zero heap-use-after-free risk, unlike `ls.c`).
- Clean multi-invocation isolation: The 10 scalar static variables are re-zeroed at the start of `main()` via the `setlocale` expansion in `compat/netbsd/include/sys/file.h`, ensuring clean execution across sequential invocations within cooperative sessions.

## 4. Behavioral Test Suite Matrix (`tests/test_wc_behavior.sh`)

Twelve behavioral tests verify `wc` across all supported invocations:
1. `test_wc_default_stdin`: default `-l -w -c` counts on piped input.
2. `test_wc_lines_only`: `-l` flag on input.
3. `test_wc_words_only`: `-w` flag on input.
4. `test_wc_bytes_only`: `-c` flag on input.
5. `test_wc_longest_line`: `-L` flag on input.
6. `test_wc_multi_flag_combo`: `-l -w` combo flag formatting.
7. `test_wc_single_file`: `wc /tmp/file` with formatted counts and filename.
8. `test_wc_multi_files_total`: `wc /tmp/f1 /tmp/f2` with per-file and total lines.
9. `test_wc_pipeline_cat`: `cat /tmp/file | wc -l` pipeline integration.
10. `test_wc_empty_file`: empty file returns 0 counts without error.
11. `test_wc_missing_file_diagnostics`: missing file diagnostic and status 1 propagation.
12. `test_wc_invalid_flag_usage`: invalid flag diagnostic and status 1.
